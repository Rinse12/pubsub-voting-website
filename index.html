5chan directory votes

Which board should host each 5chan directory — /g/, /a/, /b/…? One trustless contest per directory over libp2p pubsub. Every wallet holding a 5chan Pass (a free testnet NFT on Base Sepolia — grab one at the faucet) gets exactly one vote per directory — no gas, no transaction — signed in your browser, verified by every peer against the chain, counted with no server. The highest-scoring board resolves the directory code; if it goes offline, 5chan rotates to the next-highest.

Directory manifest — the document every contest topic is derived from

Each directory's contest criteria is { ...defaults, ...entry } from this manifest (the library's deriveDirectoryCriteria), and its topic is bitsocial-votes/<CID> of that derived document (canonical dag-cbor). Every peer validates votes against these rules, so changing any byte forks that directory's contest onto a different topic. RPC endpoints are deliberately not part of the document — each client picks its own.

    Wallet

    Why a wallet? Your vote is an EIP-712 message and the signature is your voter identity — a free signature, never a transaction. These test contests are gated: only wallets holding a 5chan Pass (ERC-721 on Base Sepolia) are eligible — every peer reads your balance on-chain before counting your vote, and each directory counts your wallet once. No Pass yet? Mint one free at the faucet (solve a captcha, paste your address). Connect the wallet that holds the Pass (MetaMask etc.), or generate a throwaway wallet in this browser and feed its address to the faucet — it is saved here and restored automatically on your next visit, until you forget it (or clear site data).

    Keep your votes alive

    Votes decay on purpose: a ballot stops counting ~… after the voting window it was signed in, so a directory whose voters all fall silent ends up with an empty leaderboard and no board resolving its code. Nobody can refresh a vote for you — the seeder serves your vote but holds no key, and only the browser that signed it can sign it again. With this on, this tab re-publishes every vote you cast here (same board, same ballot, re-signed into the current window) on the interval below, and catches up anything that went stale while the tab was closed. The protocol only needs this every ~…; the shorter intervals are for exercising these test contests. Each refresh is a free signature — no gas, no transaction.

    …

    ⚠ Your wallet is an extension wallet, so every refresh asks it to sign once per vote you hold — a popup each, on every interval. A wallet generated in this browser signs silently.

    Leading board's community

    The boards on a leaderboard are pkc communities — a board's public key is its community address. This page loads the selected directory's #1 board's community through pkc-js (createCommunity + community.update()) over the same in-browser helia node the votes sync on, and follows the leader if a later vote changes it.
