5chan directory votes

Which board should host each 5chan directory — /g/, /a/, /b/…? One trustless contest per directory over libp2p pubsub. Every wallet holding a 5chan Pass (a free testnet NFT on Base Sepolia) gets exactly one vote per directory — no gas, no transaction — signed in your browser, verified by every peer against the chain, counted with no server. The highest-scoring board resolves the directory code; if it goes offline, 5chan rotates to the next-highest.

Directory manifest — the document every contest topic is derived from

Each directory's contest criteria is { ...defaults, ...entry } from this manifest (the library's deriveDirectoryCriteria), and its topic is bitsocial-votes/<CID> of that derived document (canonical dag-cbor). Every peer validates votes against these rules, so changing any byte forks that directory's contest onto a different topic. RPC endpoints are deliberately not part of the document — each client picks its own.

    Wallet

    Why a wallet? Your vote is an EIP-712 message and the signature is your voter identity — a free signature, never a transaction. These test contests are gated: only wallets holding a 5chan Pass (ERC-721 on Base Sepolia) are eligible — every peer reads your balance on-chain before counting your vote, and each directory counts your wallet once. Connect the wallet that received the Pass (MetaMask etc.), or generate a throwaway wallet in this browser and ask the Pass owner to airdrop to it — it is saved here and restored automatically on your next visit, until you forget it (or clear site data).
